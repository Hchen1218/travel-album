# 声音：全部现场合成

声音不是背景音乐，它是照片情绪的第三个层面（原理 4）。整个站不放任何音频文件，所有声音都用 Web Audio 在浏览器里现场合成（原理 5）。

## 1. 硬规则

- **开启时机**：`THEME.soundOn` 默认开启。若浏览器允许自动播放，加载后直接接通；否则在首次 `pointerdown`、`pointerup`、`touchend` 或 `keydown` 时恢复播放（`sndFirst`）。触摸结束事件用于兼容移动浏览器。滚轮和悬停不算用户操作。顶部的 Sound 按钮可以关掉，关闭后后续手势不会自动重新开启。
- **启用与播放分开**：`SND.on` 是用户的开关选择，`sndReady()` 判断音频是否实际运行。只有 `sndReady()` 为真时才排声音，避免在浏览器暂停自动播放时积压音符。均衡器只在实际播放时跳动。
- **总线**（`sndInit`）：
  - `SND.out` 接压缩器（threshold -16、ratio 8），再接扬声器，作用是防爆音；
  - `SND.fx` 走悬停音、转场和大图音；
  - `SND.lp` 是章节环境声，前面有一个低通滤波器；
  - `SND.wet` 是卷积混响。
- **让位**：打开大图时，`sndDuck(true)` 把环境声压到 30%，并让它变闷（低通 750Hz）。
- **切走标签页再回来**时，不补放积压的音（`sndTick`）。
- **音量预算**：参照本站实测，打开大图那几秒的峰值在 0.10–0.32 之间，各章之间相差不超过 3 倍。某一章明显偏响时，降它的乐器力度 `v`，不要动总线。
- **环境声总音量**：`THEME.presence`，对应 DNA 的 `sound.presence`。

## 2. 乐器表（`V.*`）

| 乐器 | 签名 | 音色 | 适合的情绪 |
|---|---|---|---|
| `bell` | `(f, t, dest, v)` | FM 钟，长尾 | 仰望、庄严、寺院、高处 |
| `pluck` | `(f, t, dest, v)` | Karplus-Strong 拨弦，像琴或古筝 | 传统、手工、朱红、慢走 |
| `synth` | `(f, t, dest, v, dur)` | 两个走音的锯齿波，低通往下扫 | 霓虹、夜、电子、速度 |
| `keys` | `(f, t, dest, v, dur)` | 正弦加泛音的 lo-fi 电钢 | 室内、食物、日常、怀旧 |
| `wood` | `(f, t, dest, v)` | 短促的木琴音 | 绿荫、童趣、木结构、市集 |
| `chirp` | `(t, dest, v)` | 鸟鸣 | 自然、清晨 |
| `swoosh` | `(t, dest, v, dur)` | 一阵风（噪声扫频） | 转场 |
| `wind` | `(t, dest, v, dur, f0, f1, q, type)` | 可调的噪声扫频 | 风、海浪、聚拢 |
| `riser` | `(t, dest, v, dur, f0, f1, root)` | 锯齿和弦，滤波器上扫 | 霓虹的期待感 |
| `vinyl` | `(t, dest, v, dur)` | 黑胶底噪 | 怀旧、胶片 |

持续声源（环境层用）：
- `loopNoise(dest, buf, type, freq, q, gain)`：循环噪声，用来做风、海、城市低鸣、雨；
- `drone(dest, f, type, gain)`：持续音；
- `lfo(param, rate, depth)`：让一个参数慢慢起伏。

**新乐器**：照片需要表里没有的音色时，比如马林巴、钢鼓、手风琴、冰裂、雨滴，就在 `Object.assign(V, {...})` 里加一个。写法跟现有乐器一样：
- 签名统一是 `(f?, t, dest, v, ...)`；
- 用 `env()` 包络；
- 用 `t` 排程，不用 `setTimeout`；
- 每个源都要 `stop`。

几个常用的合成法：

| 音色 | 做法 |
|---|---|
| 马林巴 | 正弦，加 4 倍频的泛音，衰减 0.4s |
| 钢鼓 | 正弦，加略高于 2 倍频的泛音，起音稍软 |
| 雨滴 | 极短的正弦，从高频快速下滑 |
| 冰裂 | 高通噪声，加极短包络，随机间隔 |

## 3. 音阶：按地点和情绪选

`THEME.scale` 是一个八度里的半音位置，`THEME.base` 是 MIDI 基准音。`hz(音级, 八度, 基准)` 会自动按音阶取音，所以换了音阶，整站的旋律都跟着换。

| 地点 / 情绪 | scale | 备注 |
|---|---|---|
| 日本（本站） | `[0,1,5,7,8]` 都节音阶 | 有小二度，幽微 |
| 日本乡间、海边、田园 | `[0,2,5,7,9]` 阳音阶（民谣音阶） | 开朗、朴素，没有半音 |
| 日本南部、冲绳 | `[0,4,5,7,11]` 琉球音阶 | 明亮、海岛 |
| 中国 | `[0,2,4,7,9]` 宫调五声 | 平和、开阔 |
| 印尼、巴厘 | `[0,1,3,7,8]` pelog 近似 | 金属感，配钟或钢鼓 |
| 印度 | `[0,1,4,5,7,8,11]` Bhairav | 七声，旋律走得慢一些 |
| 中东、北非 | `[0,1,4,5,7,8,10]` Hijaz | 增二度 |
| 西班牙、拉美 | `[0,1,4,5,7,8,10]` 弗里吉亚属音阶，或 `[0,2,4,5,7,9,11]` 大调 | 市集、热闹的地方用大调 |
| 北欧、冰岛、雪山 | `[0,2,4,6,7,9,11]` 利底亚 | 悬浮、冷、发光 |
| 欧洲城市、无明确地域 | `[0,2,4,7,9]` 大调五声 | 不会出错的默认 |
| 雨、夜、忧郁 | `[0,3,5,7,10]` 小调五声 | |

`base` 的选法：明亮、轻快的取 62–67，沉、暗的取 55–60。

注意：音阶长度会影响"音级"的含义。五声音阶里音级 5 就是高八度；七声音阶里，高八度是音级 7。`lpListen` 把亮度映射到 0–9 级，在七声音阶里大约覆盖 1.3 个八度，不用改。

## 4. 每章三套声音

三个数组的顺序都对应 `CHAPTERS`，写在「声音：风格区」里。

### 4.1 环境声 `SCENES[i] = b => ({ nodes, tick })`

环境声 = **底层** + **事件层**。

- **底层**：放进 `nodes` 的持续声源，切章时会自动停掉。来源是 `loopNoise`、`drone` 和 `lfo`。
- **事件层**：`tick(t)` 在时间 `t` 排一个或几个音，然后返回下一次的时间。用 `rnd()` 和 `pick()` 给它一点不规则。

本站 6 章的拆解，可以照这个思路举一反三：

| 章 | 底层 | 事件层 | 节奏 |
|---|---|---|---|
| 高塔 | 低通噪声（城市低鸣），加 55/82Hz 持续音 | 偶尔一声钟 | 3.2–6s 一次 |
| 霓虹 | 无 | 16 分音符合成器琶音，两小节换一个和弦，每拍加低音 | 112 BPM |
| 朱红 | 无 | 稀疏的拨弦，30% 概率带倚音 | 0.4–1.6s |
| 绿荫 | 带通噪声（风），用 LFO 让频率和音量起伏 | 1–3 声鸟鸣 | 1.6–4.2s |
| 漫游 | 低通噪声，加慢 LFO（海浪），再加三和弦铺底 | 高音拨弦 | 4–7s |
| 小事 | 黑胶底噪 | 电钢四和弦循环 | 76 BPM，两拍一个和弦 |

配方原则：
- **越安静的照片，事件越稀。**自然类每 2–7 秒一次，城市夜景可以连续。
- **底层决定"在哪里"，事件层决定"什么心情"。**比如：
  - 海边 = 海浪底层 + 稀疏高音；
  - 雨夜 = 雨声底层 + 电钢；
  - 市集 = 人声般的带通噪声 + 木琴或马林巴的切分节奏。
- 每章至少在底层、乐器、节奏三者中的两项上跟相邻章不同。

### 4.2 悬停音色 `VOICE[i] = (f, t, dest) => …`

首页悬停某章的照片时，用这一章的乐器弹一个音。一般选这一章事件层的主乐器。

悬停音触发得最频繁，最容易刺耳，所以有几条额外规矩：
- **音高由照片决定**：`sndHover` 用 `photoLum` 读照片的平均亮度，暗照片低、亮照片高（音级 0–7）。不要用"第几章、第几张"去算音高。
- **不往上翻到 1–4kHz**：那是人耳最敏感的频段。要升八度时用 `up8()`，超过 900Hz 就不升。
- **用柔和版乐器**：`V.bell`、`V.synth`、`V.pluck` 的最后一个参数 `soft` 设为 true，分别对应 FM 调制深度封顶、共振压低、起音噪声磨圆。
- **音量按实测响度拉平**：拨弦和锯齿波的峰值高，按 RMS 拉平后，拨弦约 0.2，锯齿约 0.05。
- 悬停音走 `SND.hov` 总线，上面有一道 3.2kHz 的柔和低通；两次触发至少间隔 90ms。

### 4.3 大图事件音 `LB_SND[i] = { open, step, done, look, swap, close }`

| 事件 | 时机 | 写法 |
|---|---|---|
| `open(t)` | 粒子开始聚拢 | 一个"聚气"的声音：`wind` 上扫、`riser`、黑胶起声 |
| `step(t, j)` | 显影每升一级，j = 0–6 | 音级随 j 上行，力度很小；7 级连起来是一条上行音阶 |
| `done(t)` | 成像完成 | 一个落地的和弦或重音，是整套里最"满"的一声 |
| `look(t, d, v)` | 放大镜划过；d = 亮度对应的音级（0–9），v = 饱和度对应的力度 | 用这章的主乐器，`v` 乘一个很小的系数，因为会频繁触发 |
| `swap(t)` | 左右切换照片 | 短促的过渡音 |
| `close(t)` | 关闭，粒子飞回 | 一段下行琶音，跟 `open` 呼应 |

`arp(t, 音级数组, 间隔, (音级, 时间) => …)` 用来写琶音。

## 5. 首页的声音：`RING_SND`

在「声音：风格区」的最前面：
- `melody`：照片环每滚过一格，弹旋律里的下一个音级，自动高一个八度；
- `step`：弹旋律的乐器，默认 `V.pluck`，可以按 DNA 换成主乐器；
- `chime`：风格台切换时的一声，默认 `V.wood`。

页面转场的风声 `sndSwoosh` 在引擎里，一般不用改。

## 6. 验证

不能只看代码，要实际测峰值。步骤：

1. 进入某一章（`#/ch/N`），**等 2 秒**，让幕布转场的风声过去、环境声淡入稳定。
2. 开声，接一个 AnalyserNode，然后用 `lbFromPic` 点开一张照片。不要用改网址的方式打开，那样可能又触发一次幕布和风声。
3. 量 3 秒的峰值，然后关闭大图。
4. 每章**测 3 次，取中位数**。环境声是随机排的，单次能差 1.5 倍。

```js
setSound(true);
const an = SND.ac.createAnalyser(); SND.out.connect(an); let peak = 0; const b = new Float32Array(2048);
const iv = setInterval(()=>{ an.getFloatTimeDomainData(b); for (const v of b) peak = Math.max(peak, Math.abs(v)); }, 20);
lbFromPic(CH.figs[0].el.querySelector(".pic"));
await new Promise(r=>setTimeout(r, 3000)); clearInterval(iv); peak;   // 记下来，再 lbRequestClose()
```

每章的中位数都要落在预算内，改完力度以后要整轮重测。浏览器面板在后台时 `requestAnimationFrame` 可能暂停，大图会卡在聚拢阶段，先截一张图把页面唤醒。

最终的听感要请用户自己听。测量只能保证不爆、不哑。
