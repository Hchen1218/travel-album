# 部件：契约、旋钮、同级替代

模板 `index.html` 由 7 个部件组成。每个部件都写了三样东西：

- **契约**：不能丢的体验。换掉这个部件时，新形式也要做到这些。
- **旋钮**：DNA 往哪里填。大部分在 `THEME`、`:root`、`CHAPTERS` 里。
- **同级替代**：什么样的 DNA 会跟默认形式冲突，可以换成什么，大致怎么改。

**替换规则**
- 一个站最多替换 2 个部件。
- 每次替换都要在 DNA 的 `swaps` 里写清楚：是哪条 DNA 跟默认部件冲突。
- 替换只改这个部件内部，对外接口保持不变（函数名、`route`、`CH.figs`、`LB` 的字段），这样其他部件不用跟着改。

代码位置用函数名标注，不用行号。行号会随着修改漂移，用编辑器搜函数名即可。

## 1. 首页照片环

`layoutRing` · `renderRing` · `tileEl` · `ringTiles` · `nudge` · `loop`

**契约**
- 所有照片同时在场，都以方图缩略呈现。
- 照片持续流动，可以用滚轮、触摸、方向键推动，松手后带惯性。没人操作时自己慢慢转，鼠标停在照片上时暂停。
- 每次滚过一格会触发一个音（`sndStep`）。
- 悬停照片时通知点阵字（`hoverChapter`）。
- 手机使用全宽粒子舞台和可滑动的照片带，横屏时照片带位于右侧；照片是预览按钮，重复点击也不跳转。只有独立的「进入章节」按钮可以跳转，滑动不误触且保留当前预览。
- 照片中间穿插两块文字砖（`TEXT_TILES`）。

**旋钮**
- `THEME.motion.drift`、`THEME.motion.follow`；
- 文字砖的内容和位置：`ringTiles` 里的 `splice(3)` 和 `splice(17)`；
- 照片不到 24 张时，`ringTiles` 会循环补满，不用另外处理；
- 横屏和竖屏下的行列数，在 `layoutRing` 里。

**同级替代**

| 冲突的 DNA | 换成 | 改法要点 |
|---|---|---|
| 动效性格是"漂浮"，照片多是自然、海 | 无限网格缓慢漂移：整面墙斜向移动，边缘循环 | 在 `renderRing` 里把四条边带改成二维网格，用 `mod` 处理循环；`ring.u` 改成二维向量 |
| 胶片质感、复古 | 横向胶片带：上下各一条，方向相反 | `layoutRing` 只保留上下两个 strip，tile 加齿孔装饰（用 CSS 画，不用图片） |
| 照片少于 8 张 | 照片堆：照片叠在中间，滚动时一张张抽到顶上 | `renderRing` 改成按 `ring.u` 计算每张的 z 值和偏移；点阵字移到上方 |

## 2. 点阵大字

`wordPoints` · `sampleDots` · `setShape` · `photoTint` · `tintAt` · `stepDots` · `hoverChapter`

**契约**
- 首页的大字（`THEME.home.word`）由粒子组成，粒子会躲开鼠标，然后弹回原位。
- 悬停某张照片时，粒子重组成那一章的名字，并逐点染上那张照片的颜色。
- 平时粒子是强调色。
- 手机预览使用更大的画布，并用约一秒的有序路径展示形状和照片取色的变化；变形结束后才启用进入按钮。减弱动态效果偏好下直接显示结果。

**旋钮**
- `THEME.font`；
- `THEME.motion.spring`、`damp`、`repel`；
- `P.step`（取点间距）、`P.r`（点半径）；
- `tintAt` 里的饱和度提升系数（1.4）。

**粒子形态**：是旋钮，不算替换，不占"最多 2 个"的名额。只改 `stepDots` 末尾的画法，不动物理。

| 粒子形态 | 改法 |
|---|---|
| square | `ctx.fillRect(d.x - P.r, d.y - P.r, P.r*2, P.r*2)` |
| glyph | `ctx.fillText(ch, d.x, d.y)`。每个点固定一个字符，按亮度从 ` .:-=+*#%@` 里选；字体用等宽体 |
| line | 按速度方向画短线：`moveTo(d.x - d.vx*2, d.y - d.vy*2)`，再 `lineTo(d.x, d.y)`，静止时是竖线 |
| 发光（夜景） | 深色纸，画两遍：第一遍用 `globalCompositeOperation = "lighter"` 画大半径、低透明的光晕，第二遍画实心点 |

注意：`stepDots` 里有一个"全是强调色时一笔画完"的快速路径，改画法时两条路径要一起改。

## 3. 章节页

`buildChapter` · `measureChapter` · `renderChapter` · 拖动相关（`chV` 的 pointer 事件、`endDrag`）

**契约**
- 照片保持原始比例，铺满视口高度。
- 横向滑动带惯性，带视差。
- 每张照片下有一句图注；第三方作品带署名（`credit`、`license`）。
- 点一下照片打开大图，拖动不会误开（移动 < 6px 且 400ms 内松手才算点击）。
- 前一章、后一章的链接，进度条。

**旋钮**
- `THEME.motion.follow`；
- 视差强度，在 `renderChapter` 的 `rel` 系数里；
- 图片间距、图注的样式。

**同级替代**

| 冲突的 DNA | 换成 | 改法要点 |
|---|---|---|
| 照片大多是横图（`portrait_share` < .3）且性格是"柔软" | 纵向长卷 | `CH.x` 改作纵向位移，translate 改成 Y 轴，视差也改到纵向；保留 `CH.figs[i].el` 和 `.pic` 结构，大图要靠它们找缩略图 |
| 杂志、印刷感很强 | 杂志对页：一次显示两张，翻页式切换 | 横滑保留，但按页吸附（`CH.tx` 吸到页边界），页间加中缝 |

## 4. 风格台

`STYLES` · `FX_FN` · `fxInk` · `fxDot` · `fxBlock` · `coverCanvas` · `paintFx` · `setStyle`

**契约**
- 在浏览器里实时把整章照片"印"成另一种样子：原图加 3 种。
- 键盘 1–4 可以切换。
- 至少一种效果能给出照片的调色板（返回 `palette`）。
- 大图会用同一个效果显影（`lbSource`）。
- 第三方风格作品（带 `credit` 的照片）永远保持原样。

**效果函数的接口**

```js
function fxName(img, W, H){            // img：已经解码的 <img>；W×H：要输出的像素尺寸
  const g = coverCanvas(img, W, H);    // 先把照片按 cover 方式铺进 W×H 的画布
  // ……逐像素处理，只用 PAPER、INK、ACCENT 和照片自己的颜色……
  return { canvas:g.canvas };          // 能给调色板的话，再带上 palette:[{hex, share, light}]
}
```

新增效果分三步：写好函数；加进 `FX_FN`；在 `STYLES` 里登记 `{ id, zh, en }`。数量保持 4 个，因为键盘 1–4 是写死的。

**可选效果的做法**（都只用照片像素加 PAPER、INK、ACCENT）

| 效果 | 做法 |
|---|---|
| 蓝晒 cyanotype | 亮度映射到 PAPER 和"照片调色板里最深的蓝"之间；照片里没有蓝，就不要选这个效果。再加纸纤维噪声 |
| riso 双色 | 亮度分两档，分别印 ACCENT 和第二色（第二色取照片调色板里离 ACCENT 色相最远的那个）；两版错位 1–2px |
| 像素马赛克 | 缩到 1/16 再最近邻放大，颜色量化到调色板的 8 色 |
| 扫描线 | 每隔 n 行取一行，行高随亮度变化；底色用 INK |
| ASCII | 按格子亮度选字符，用 `fillText` 画；字符颜色取格子平均色 |
| 线稿 | 用 Sobel 求边缘，边缘画成 INK，其余留 PAPER |
| 木刻双色 | 亮度阈值分出黑版，叠加 ACCENT 色的平涂大色块（来自调色板） |

性能约束：效果在主线程跑，`measureChapter` 会把画布限制在 1100px 以内。逐像素循环里不要分配对象。

## 5. 单张大图

`lbOpen` · `lbSwitch` · `lbRestyle` · `lbClose` · `lbDots` · `lbDrawDots` · `lbLevel` · `lbDrawDev` · `LB_STEPS` · 放大镜 `LP` · `lpMove` · `lpDraw` · `lpListen`

**契约**
- 打开：粒子从缩略图当前的位置飞出（沿曲线、错峰、到位时轻微冲过头），由粗到细显影成照片，再淡入原图。
- 当前风格不是原图时，显影成那个风格。
- 放大镜里永远是原片。放大到原图一个像素占 2.5 个点以上时，直接显示像素格。
- 侧栏显示指针下的色号、照片的 5 个主色（点击可复制）、署名。
- 支持左右切换、1–4 换风格、Esc 和点空白处关闭、浏览器返回键关闭。
- 网址 `#/ch/章/张/view` 可以直接分享。
- 手机上是底部抽屉，按住拖动放大镜。

**旋钮**
- `THEME.motion.gather`、`develop`；
- `LB_STEPS`（点阵从粗到细的格距）；
- 放大镜尺寸（桌面 210 / 手机 150）、默认倍数 `LP.z`；
- 各段时长：切换 420+1000，换风格 380+700，关闭 450+750。

**同级替代**：只换显影方式，飞出和放大镜保留。

| 冲突的 DNA | 显影方式 | 改法要点 |
|---|---|---|
| 质感是扫描线、复古显示器 | 扫描线显影：从上到下逐行扫出，行先粗后细 | 改写 `lbDrawDev(k)`，`k` 是 0–1 的进度，用它决定扫到哪一行、行高多少 |
| 粒子形态是 square 或 glyph | 马赛克或字符显影：格子由大到小 | `lbLevel` 里把 `arc` 换成 `fillRect` 或 `fillText`，`LB_STEPS` 不变 |
| 胶片 | 暗房显影：整张从全白慢慢浮出，先出暗部 | `lbDrawDev` 里按亮度阈值从低到高逐步显示，叠一层 PAPER 并淡出 |

## 6. 声音

`SND` · `sndInit` · `V.*` · `SCENES` · `VOICE` · `LB_SND` · `sndScene` · `sndHover` · `sndStep` · `sndDuck` · `sndFirst`

**契约**
- `THEME.soundOn` 控制进站默认开关，默认开启；浏览器限制自动播放时，在第一次有效触摸或按键时接通，滚轮不算。用户手动关闭后，后续操作不能自动重新开启。
- 首页悬停照片时出一个音，滚动照片环时连成一段旋律。
- 每章一种环境声，大图里每章一套事件音（open、step、done、look、swap、close）。
- 全部现场合成，大图打开时环境声让位。

**旋钮**
- `THEME.scale`、`THEME.base`；
- `SCENES`、`VOICE`、`LB_SND` 三个数组，顺序对应 `CHAPTERS`。

详见 `sound.md`。

## 7. 路由和转场

`parse` · `go` · `show` · `curtain`

**契约**
- `#/` 是首页，`#/ch/N` 是章节，`#/ch/N/M` 是章节内第 M 张，`#/ch/N/M/view` 是大图。
- `#/about` 是作者页，沿用章节的幕布转场；返回链接回到进入前的相册页面，支持浏览器前进、后退和直接打开。
- 浏览器的前进、后退都能用。
- 页面之间用幕布转场。

**旋钮**：幕布颜色（默认是强调色）、时长（520ms）。幕布上的字是章节名，回首页时是 `THEME.home.word`；缓动跟着 `--ease` 走。

转场途中网址又变了（比如幕布还没拉开就跳到 `/view`）时，`go()` 会用 `goTok` 以最新的网址为准。

通常不替换。
